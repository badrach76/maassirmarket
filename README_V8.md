# سوق معاصر المغرب — MAASSIR MARKET V8

## ما الجديد
- شعار المنصة المعتمد هو الصورة الرسمية المرفقة من صاحب المشروع: `logoSAM.png`.
- هوية موحدة: **سوق معاصر المغرب / MAASSIR MARKET**.
- رأس موقع موحد ومتجاوب مع الهاتف مع قائمة محمولة احترافية.
- شريط مؤشرات زيت الزيتون في أعلى الصفحة، سريع الحركة، ويعرض مؤشرات مرجعية يومية من Olea Price.
- ملف مهني + حساب + صفحة عامة.
- دليل المعاصر والمسوقين مع نوعية الزيت وسعر البيع وتاريخ التحديث.
- النشر المجاني أو طلب النشر المميز المدفوع؛ المدفوع يدخل حالة `pending_payment` إلى حين تأكيد الإدارة.
- دعم روابط الصور والفيديوهات داخل الإعلانات.
- حفظ الوسائط المحلية في IndexedDB للنسخة التجريبية، ودعم الروابط العامة للصور/الفيديو.
- `supabase-schema.sql` جاهز لنقل الحسابات والإعلانات والوسائط والأسعار والإشهار إلى قاعدة بيانات حقيقية متعددة المستخدمين.

## مؤشرات الأسعار
البيانات الموجودة في `prices.json` هي لقطة مرجعية بتاريخ 2026-10-04 من Olea Price. يتم تحميل الملف عند فتح الصفحة مع محاولة تحديثه دون كسر الموقع إذا تعذر الوصول إليه.

للتحديث الحقيقي التلقائي يومياً بين جميع المستخدمين، يُنصح بربط `price_indicators` بـ Supabase Edge Function / Cron ومصدر البيانات المعتمد، ثم جعل الواجهة تقرأ من قاعدة البيانات.

## ملاحظة مهمة عن الحسابات
V8 يوفر تجربة الحسابات والصفحات محلياً حتى يمكن اختبار الواجهة دون مفاتيح خارجية. لكي يصبح الحساب حقيقياً متعدد الأجهزة، يجب تنفيذ Supabase Auth + RLS + Supabase Storage وفق `supabase-schema.sql`.
